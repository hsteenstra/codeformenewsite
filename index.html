WHY CODE FOR ME

Computer science belongs everywhere.

We started Code For ME because students shouldn't have to travel far, spend hundreds of dollars, or already know how to code to get started.

Our goal is simple: make coding approachable enough for a beginner and exciting enough that they want to keep going.

FOUNDED IN BATH, MAINE
OUR STORY

It started with a missing opportunity.

Code For ME was created after seeing how few programming opportunities were available locally for students who wanted to learn.

What started as an interest in computer science became a mission to make those opportunities easier to find and easier to afford.
