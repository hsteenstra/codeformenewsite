WHY A SANDBOX?

Because the best way to learn code is to write code.

Reading about programming is useful. Watching someone else code is useful too.

But eventually, you need to open the editor and try it yourself.

01

No setup

Students can start experimenting without installing Python or configuring a development environment.

02

Experiment freely

Change code, make mistakes, run it again, and figure out what happens.

Built for beginners
